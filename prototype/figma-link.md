# ATITHI — Figma Design & Prototype

## Live Figma File

- **Design & Prototype Link:** [Open ATITHI in Figma](https://www.figma.com/design/ExJ4iCur5gL5o8fWuVqOIX/Atithi?node-id=0-1&t=Cy7qbnhQN4zsb8PA-1)

## What Is Included

This Figma file contains the **Phase 1 UI/UX design** for the ATITHI guest-first restaurant ordering experience, structured around the core user journey:

`Discover → Choose → Customize → Order → Pay → Track`

## How to Explore

1. Open the Figma link above.
2. Browse the mobile UI frames arranged across the canvas.
3. Click the **Present (`▶`)** button in the top-right corner of Figma to preview interactive screen transitions *(where prototype links are connected)*.

## Scope Note

- **Current Phase (Implemented in Design):** Guest-facing digital dining and ordering UI/UX in Figma.
- **Planned Future Phases:** Brand identity finalization, frontend/backend application development, restaurant/kitchen management workflows, and live payment integration.
